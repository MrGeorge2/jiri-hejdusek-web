# jiri-hejdusek-web

**Personal website — Jiří Hejdušek, .NET developer.**

Single-page personal website showcasing skills, experience, and services. Built with vanilla HTML, CSS, and JavaScript, served via GitHub Pages.

## Tech

- HTML5, CSS3, vanilla JavaScript
- Docker (Nginx) for local development
- GitHub Pages for hosting

## Live

👉 [mrgeorge2.github.io/jiri-hejdusek-web](https://mrgeorge2.github.io/jiri-hejdusek-web/)

## Run Locally

```bash
docker build -t jiri-web .
docker run -p 8080:80 jiri-web
```
